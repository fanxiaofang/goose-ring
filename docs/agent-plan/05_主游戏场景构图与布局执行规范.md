## 1. 当前确认与评审边界

- 用户在参考原型对比 25°、30°、35°、40° 后，确认默认 **透视相机、垂直 FOV 30°**。俯视 30°，水平偏航 0°。代码默认模式为 `persp30`，正交、透视25°和35°保留调试。
- 正式场同时在栏内的鹅最多 **8 只**。场地尺寸、鹅的显示尺度和活动空间继续评审。
- PWA 场景参考 `goose-test` 的低前栏、栏外站位提示和清楚的前后层次。前栏中央柱顶与横杆上缘齐平，其余立柱带深色柱帽和石脚。默认镜头按围栏角柱外沿与 5.74 m 站位垫前横木自适应，在窄视口后拉。
- 大厅右侧竖向广告位只在大厅显示。广告位与顶部模式入口分开，进入投掷态隐藏。
- 手机横屏核心视口为 844×390、667×375 CSS px，按实际安全区复核。
- 旧版正交草图已被用户否决。旧版围栏占比、左右对称留白、顶部 64 px、底部 56 px、头颈像素门槛、最多 10 只与摊主尺寸均由 Agent 提出，未获用户批准，退出执行验收条件。
- 场地世界尺寸、鹅的视觉大小、摊主尺度、广告位尺寸、顶底空间和大厅/投掷镜头是否完全一致继续评审。现有 16×10 m 和 8 鹅只作为回看代码与本轮草图的对照样本。

## 2. 信息与入口（2026-11-24 评审更新，本表为当前讨论基线）

核心转变：**从「大厅 / 正式投掷 / 练习投掷」三界面，收敛为「大厅 + 单一投掷场」两界面**。大厅只管**庙会币**，圈是进场时才用币兑换的临时凭证；大厅不显示「圈库存」。

### 2.1 模式（4 个入口，围栏上方横排）

入口本质是「围栏里鹅的行为配置」，不再是三套独立界面：

| # | 模式（命名待定，见 2.4） | 鹅配置 | 计圈/累计 | 进入条件 |
|---|---|---|---|---|
| 1 | 练习场 | 1 只鹅，仅待机动画、原地不动 | 不计圈、可无限投、不计累计 | 免费 |
| 2 | 静态场 | 8 只静态（当前布局），各自随机待机动画 | 计正式圈、计累计 | 免费 |
| 3 | 普通场 | 8 只走动 | 计正式圈、计累计 | 免费 |
| 4 | 机灵场 | 8 只高难（含鹅王） | 计正式圈、计累计 | **看广告解锁（范围待定，见 2.4）** |

### 2.2 各界面信息与入口

| 界面 | 必须看见的信息和入口 | 展开内容 |
|---|---|---|
| 大厅 | 庙会币余额（含领今日 20 币）、**个人累计套鹅数**、独立「兑换」牌子、排行榜（合并个人纪录）、设置；围栏上方横排 4 模式卡 | 兑换面板（币→圈）、榜单页（顶部个人纪录 + 榜单）、设置面板 |
| 投掷场 | 剩余圈（圈图标+数字）、本盘已套（对勾+数字）、个人累计（鹅头图标+数字）、辅助开关、设置、暂停入口（待定）、当前模式名 | 暂停菜单：继续 / 退币收摊 / 换盘 / 排行榜 / 设置 |
| 结算页（圈耗尽） | 本盘战绩、剩余币、补币文案 + 规则 + 入口 | 一键换圈再来一盘 / 看广告领币 / 回大厅 |

### 2.3 关键交互规则

- **兑换前置**：大厅设独立「兑换」牌子；点模式卡时若币不足，弹轻引导「先去兑换 / 看广告领币」，不卡死。投掷场圈耗尽 = 本盘结束，进入**结算页**，兑换/补币动作全部收敛在结算页，**不在投掷中途弹浮条**。
- **圈 → 币返还**（暂定基线 A，见 2.4）：退出/暂停时剩余圈按币返还。
- **辅助开关**：投掷场 HUD 单独拎出一个常驻小图标（三档即时切换），设置面板里保留一份作为「默认档」。
- 历史累计由成功即时保存更新，清摊另记成就。

### 2.4 暂定基线（2026-11-24 已确认；命名后续会重新定）

| 项 | 暂定值 | 备注 |
|---|---|---|
| 模式命名 | 练习 / 静态 / 普通 / 机灵 | **暂定名，后续会重新命名**；三套命名候选（庙会口语 / 鹅性格 / 难度信号）留待重命名时再选 |
| 广告解锁范围 | 只锁机灵场 | 解锁形态：看一次广告解锁当日机灵场 |
| 圈→币返还 | 方案 A 全额返还 | 需加防滥用约束：进场至少投 1 圈、24h 内反复进出限次 |

## 4. 评审顺序

1. 确认大厅、正式投掷与练习的信息内容正确。
2. 在透视30°下讨论围栏占屏、鹅的大小、顶部/底部空间与广告位。
3. 加入摊主候选占位后评估最多 8 只鹅的活动空间。现有 16×10 与 8 鹅能作对照，是否缩场或改模型大小须结合图稿与可达性证据。
4. 先在两款视口与实际安全区下核对完整性，形成批准的像素预算，再写入 PL 验收条件。
5. P0-L 通过后进入 P0-A，逐只复现真实投掷与入颈路径。左后鹅及后排余量问题见 [决策与参数](04_决策与参数.md)。
