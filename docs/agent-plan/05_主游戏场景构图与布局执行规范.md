# 《鹅有一套》主游戏场景构图与布局评审稿

Agent 执行包 v0.2 · P0-L · 修订待讨论

> 口径提示：本文第 3 节是上一轮 FOV25° 草图记录（出手 1.45 m / 初速 11 m/s）。现行基线为 FOV30°、出手 `(0, 1.85, 6.10)`、仰角 30°、最高 11.8 m/s，以 [04 D-017](04_决策与参数.md#d-20261124-017-前栏立柱木栈道与投掷校准) 和代码为准。

## 1. 当前确认与评审边界

- 用户在参考原型对比 25°、30°、35°、40° 后，确认默认 **透视相机、垂直 FOV 30°**。俯视 30°，水平偏航 0°。代码默认模式为 `persp30`，正交、透视25°和35°保留调试。
- 正式场同时在栏内的鹅最多 **8 只**。场地尺寸、鹅的显示尺度和活动空间继续评审。
- PWA 场景参考 `goose-test` 的低前栏、栏外站位提示和清楚的前后层次。前栏中央柱顶与横杆上缘齐平，其余立柱带深色柱帽和石脚。默认镜头按围栏角柱外沿与 5.74 m 站位垫前横木自适应，在窄视口后拉。
- 大厅右侧竖向广告位只在大厅显示。广告位与顶部模式入口分开，进入投掷态隐藏。
- 手机横屏核心视口为 844×390、667×375 CSS px，按实际安全区复核。
- 旧版正交草图已被用户否决。旧版围栏占比、左右对称留白、顶部 64 px、底部 56 px、头颈像素门槛、最多 10 只与摊主尺寸均由 Agent 提出，未获用户批准，退出执行验收条件。
- 场地世界尺寸、鹅的视觉大小、摊主尺度、广告位尺寸、顶底空间和大厅/投掷镜头是否完全一致继续评审。~~现有 16×10 m~~ 围栏宽度已于 2026-11-26 改为 **14×10 m**（见 [04 D-20261126-003](04_决策与参数.md)），8 鹅布局不变。
- **摊主（后续美术阶段）**：位于围栏**内侧后部**，**沿左右方向来回巡逻**，不固定在左下或右下角（2026-11-26 确认）。预留活动带取远栏内沿与后排鹅之间：Z ∈ [-4.4, -3.9]、X ∈ [-5.8, 5.8]，约 1.2 m² 的纵深。实现时必须：建 Rapier 碰撞体并每物理步同步、纳入取景点击集、巡逻到中轴时不得长时间停在最远鹅正后方（遮挡风险）。

## 2. 信息与入口（2026-11-24 评审更新，本表为当前讨论基线）

核心转变：**从「大厅 / 正式投掷 / 练习投掷」三界面，收敛为「大厅 + 单一投掷场」两界面**。大厅只管**庙会币**，圈是进场时才用币兑换的临时凭证；大厅不显示「圈库存」。

### 2.3 关键交互规则

- **单场券**：练习直接进场，正式模式先选场、再确认兑换本场圈。「换套圈」允许先看档位。币不足时在换圈面板显示差额，暂停兑换并提供可用的领币去向。领取后保留场次和档位，刷新余额与差额。是否在缺币面板直接提供广告领取按钮，留待讨论。
- **庙会币面板**：大厅顶栏显示庙会币和余额，领取提示收进面板。面板显示余额、「免费领取今日 20 币」、已领取状态和「返回」。广告接入后的候选内容为「完整观看一条广告可领 50 币」及「看广告领 50 币」按钮。按 GDD，原型未接入时隐藏广告领取按钮，实际奖励与频次留待业务阶段确认。
- **圈耗尽与补圈续盘**。最后一圈出手后停止接受新投掷，等结果及反馈结束，再按 [GDD §11.3](GDD_v1.1_设计基线.md#113-领币兑换和补给入口如何布置2026-11-24-更新) 展示对局详情或清摊弹窗。补圈回到同一盘，保留已套进度和总投圈数。P0-L 灰盒用实际场次、已投圈数和「返回大厅」验收弹窗，P2 接入战绩与续盘流程。
- **暂停与退币**：正式场「歇口气」暂留现有位置，右下角为布局候选。暂停时冻结飞行与计时。「继续对局」接续同一场和剩余圈，「提前结束」进入收摊流程，可取消，也可确认结束并返回大厅。退币仅在确认提前结束后处理，规则沿用 §2.4 的候选口径，具体资格和算法另议。P0-L 验证继续、取消和确认退出，真实退币留待业务阶段。
- **个人记录**：大厅图标和累计只数组成可点击入口，详情按正式场次展示套中数量、投圈数与命中率，练习场不计入。排行榜仍有独立入口。个人记录是打开独立弹窗还是定位到现有页面的个人纪录区，留待评审。P0-L 确认入口位置和信息结构，真实统计及持久化按后续阶段推进。
- **辅助开关**：投掷场 HUD 单独拎出一个常驻小图标（三档即时切换），设置面板里保留一份作为「默认档」。
- **操作提示**。练习场保留简短起手提示，完整手势说明可在设置中展开。练习和静态场的起手期间，在**底部左侧**（操作区左边、不挡中央鹅群）显示两条细进度条：蓄力（从左向右填充、附百分比）与偏转（以中线为原点向左右生长、附角度），见 [04 D-20261126-005](04_决策与参数.md)。普通和机灵场只使用手持圈的姿态反馈，不显示数值。出手后清空底部提示，下一只手持圈出现时恢复起手反馈。
- 历史累计由成功即时保存更新，清摊另记成就。

## 4. P0-L 取景与灰盒

1. 修正 A 使用全屏 Canvas。默认透视的全尺寸投影窗口只平移中心，取景后拉由实际围栏、站位线、手持圈活动包络和鹅网格确定。
2. 同一份 CSS 像素布局提供四侧安全区、Play Rect、顶栏、大厅右侧广告位与投掷场底部兜底起手区。手持圈周围、站位垫及其下方连成一个连续起手区，与底部 32 CSS px 兜底带重叠。起手边界按当前投影计算，避开顶栏；合法起手后可拖出起手区再松手。
3. H5 原型根路径作为静态投掷快捷入口。正式场可经「歇口气」选择提前结束并回大厅，练习直达单鹅场。静态场使用三档难度随机站位（2026-11-26 取代原蝴蝶风筝站位），普通和机灵灰盒沿用原八鹅站位。换圈和领取用试玩余额演示，单场圈数随玩家实际投掷扣减。
4. `?layout=1` 显示测量框与头颈读数，`?ui=0` 用同一取景隐藏 HUD。`?mode=lobby`、`?mode=practice` 可直接打开相应灰盒。
5. 在两款核心视口与实际安全区下核对围栏、鹅头颈和圈的可读性、像素预算与真机触摸，确保 HUD 和起手区互不遮挡。灰盒须走通练习直达，以及正式场选场、换圈、投掷、末圈结束后看详情并回大厅，还须验证暂停后继续和提前结束。经项目负责人验收后进入 P0-A。

P0-A 验证按住、下拉或斜拉、向前甩三种投掷方式，并逐只验证真实投掷与入颈路径。同一手势中横向位移持续控制瞄准，力度综合按住时间、当前下拉距离与上拨。后排余量和具体输入参数见 [决策与参数](04_决策与参数.md)。实际退币、广告接入和完整战绩统计按后续阶段推进。

投掷场视觉调整以头颈和飞行圈为优先。当前头颈网格与对应碰撞半径增加 20%，以 852×393 布局中最小头高约 14 CSS px、最小颈宽约 8 CSS px 为构图参考。远栏和旗串降低对比。手持、蓄力和飞行的圈统一使用珊瑚红材质。
