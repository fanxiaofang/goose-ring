## 当前生效的关键基线

- 发行：微信小游戏首发；H5 原型/调试；抖音后续适配。
- 默认相机：透视 FOV 30°、俯视 30°、偏航 0°；正交、FOV25°/35°等仅调试。
- 场地：14×10 m；正式场同时最多 8 只鹅。
- 玩家模式：静态场、普通场、机灵场；单鹅模式仅内部调试直达。
- P0-2：穿越证据驱动；稳定期 0.25 s 起步；最大倾斜容忍 75°；一投最多一只；已退场鹅不再作为目标。
- P0-3：只完成动态头颈和 RingJudge/Collider 同步所必需的基础，不提前做完整鹅群 AI。
- P0-4：尽快完成普通/机灵场的漫游、察觉、延迟和躲避差异；同一套 AI 通过参数区分难度。
- 包体：微信主包/分包/总包大小必须持续记录；硬限制以当前微信官方文档和开发者工具上传校验为准，内部预算预留余量。

参数的最终生效值以 04 的最新明确决策与当前配置代码交叉核对；历史实验值不得当作现值。

## 执行与验收工作流

常规命令以当前 `package.json` 为准：
```bash
npm run typecheck
npm run test -- --pool=threads
npm run build
npm run dev -- --host 0.0.0.0
```

测试按风险控制：开发中跑受影响的定向测试；阶段结束时再跑必要的类型检查、构建和核心回归。P0-2 的 106 项是已验收历史证据，不要求在 P0-3 每个子任务反复重跑。未实际执行的命令/测试必须标为未测试。

## 不在当前 P0-3 做

完整鹅群 AI、普通/机灵模式、最终 GLB/正式骨骼美术、摊主指挥、正式累计/存档、广告、排行榜、支付、微信生产构建、抖音适配、100 次连续投圈压力测试、重做相机或投掷手势。
