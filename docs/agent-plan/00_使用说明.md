## 当前生效的关键基线

- 默认相机：透视 FOV 30°、俯视 30°、偏航 0°；正交、FOV25°/35°等仅调试。
- 场地：14×10 m；正式场同时最多 8 只鹅。
- 玩家模式：静态场、普通场、机灵场；单鹅模式仅内部调试直达。
- P0-2：穿越证据驱动；稳定期 0.25 s 起步；最大倾斜容忍 75°；一投最多一只；已退场鹅不再作为目标。
- P0-3：当前只验证可预测头颈动作、动态碰撞同步和稳定性，不做完整鹅群 AI、正式存档或商业化。

参数的最终生效值以 04 的最新明确决策与当前配置代码交叉核对；历史实验值不得当作现值。

## 执行与验收工作流

常规命令以当前 `package.json` 为准：
```bash
npm run typecheck
npm run test -- --pool=threads
npm run build
npm run dev -- --host 0.0.0.0
```

P0-3 开工前先在当前基线执行适用的类型检查、测试和构建，记录实际输出。不得把历史报告里的通过结果写成当前重新执行的结果。若环境不能运行，说明原因并标为未测试。

## 不在 P0-3 做

完整 GLB/骨骼美术、Boids 群集完整版、普通/机灵鹅 AI、摊主指挥、正式累计与存档、真实广告/排行/支付、微信/抖音生产构建、相机重做、投掷手势重做。
