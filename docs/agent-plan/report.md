## P0-A 三种手势与八鹅路径

## 2026-11-26 P0-2 套中判定 RingJudge（稳定期 0.25s 起步）

- 目标：把“环物理上卡在颈根”变成游戏认账的 `CAUGHT`，并排除撞头/撞身/侧穿/滑脱。只做判定，不计分、不做正式累计与鹅群 AI。
- 状态机：`FLYING → ENTER_NECK → SETTLING → CAUGHT | MISSED`。入颈需：环沿法线向下运动、鹅头先由下往上穿过环平面，随后颈轴由下往上穿过环平面且**落在内孔内（<0.375 m）**。锁定后颈轴持续在孔内满 **0.25 s** 判 `CAUGHT`；滑出判 `slip`。一次 `throwId` 只结算一次；多鹅同 tick 取距环轴最近者，不同 tick 取最早入颈者。
- 真机回归修正（2026-11-26 晚）：初版要求“整个头/整根颈截面都在孔内”（0.159 / 0.2454 m），真实斜抛几乎达不到，出现“环已挂在脖子上却显示 miss、计数不涨”。已放宽为“颈轴在孔内即可”、去掉稳定期单独倾斜判负，并加静止兜底（低于颈中心且颈轴在孔内即判 CAUGHT）。扫掠确认捕获窗口显著扩大。
- 关键修正（实现中发现）：初版“碰到头/身立即判负”会把合法名义投掷全部误杀——实测八只鹅的斜抛都会贴着鹅头侧面滑过 20+ tick 再套入颈。改为**穿越证据驱动**，头/身接触只作失败归因（未入颈落地/静止时回报最近 0.5 s 内的接触部位）。稳定期检查也由“颈心投影距离”改为“竖直颈轴与环平面的交点距离”，避免环倾斜时误判滑脱。
- 倾斜容忍：初定 55° 实测只允许 1/8 只名义鹅通过（鹅头穿越瞬间环最多倾斜约 69°、颈穿越约 61°），上调为 **75°**，仍能排除接近竖直的侧向穿颈。
- 退场占位：`CAUGHT` 时本盘 +1（HUD `#round-caught`）、鹅与本圈即时隐藏/移除；退场动画、音效、计分与正式累计留待后续阶段。
- 调试：`?judge=1` 显示 `RingJudge 状态 | 目标 | 结果(reason) @tick`，左上角等宽小面板，`pointer-events:none`。
- 测试：新增 `src/judge/ringJudge.test.ts` **25 项**——8 只静态鹅名义投掷全部 `CAUGHT` 且目标正确；同 8 组 +5° 偏转反例全部不 `CAUGHT`；撞头/撞身/侧穿/滑脱/多鹅同 tick 最近者/头接触不立即结算+静止归因/幂等；退场鹅排除与全退场不幽灵锁定。
- 命令与结果：`npm run typecheck` 通过；`npm run test -- --pool=threads` **104 项全部通过**（原 81 + 新增 23）；`npm run build` 通过。
- 风险 / 后续观察：① 0.25 s 稳定期是实验起点，后续真机长时间试玩可复核是否上调；② 判定状态、HUD +1、鹅即时消失的观感已真机签收（退场动画仍为占位）；③ “最近者/最早者”只在合成帧与静态场验证，走动场尚未实现。
- 下一步（已更新 2026-11-27）：P0-2 已签收；按 02 顺序进入 P0-3（鹅头颈动作、Collider 同步与压力测试）。决策记录见 [04](04_决策与参数.md) D-20261126-008。
- 退场鹅幽灵锁定修复：`RingJudge` 新增 `excludeIndices`，`GameApp` 用 `caughtGeese` 集合记录已套中的鹅并在每次新建判定器时排除；已退场鹅保留占位但不参与锁定，`gooseIndex` 仍与原始布局对齐。新增 2 项测试（排除 0 号后改判 1 号、全部退场后不幽灵锁定），全量 106 项通过。
