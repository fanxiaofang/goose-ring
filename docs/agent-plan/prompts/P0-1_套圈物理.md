# Prompt：P0-1 套圈物理（P0-0 人工通过后才使用）

上一个阶段 P0-0 已经验收，请先阅读 GDD v1.1 和技术/测试规范。本次只实现 **P0-1：有孔的真实物理圈 + 投掷**。

**目标**：从横屏底部拉动蓄力、左右修正，松手扔出一只受重力影响、能旋转、能碰地和围栏的圈。

**强制技术要求**：
1. Three.js 可视环与 Rapier 物理环形状一致；使用多个胶囊段/小凸体围成真正有内孔的复合碰撞体，不能拿实心圆盘 Collider 欺骗物理。
2. 使用动态刚体、合理质量/摩擦/弹性/角速度、固定物理步长；必要时启用 CCD/子步进。
3. 场景显示手势力度和方向，圈的运动和飞行时间有可调参数；只支持合法投掷手势，避免误触。
4. 调试面板显示 ring collider、速度、姿态、实际撞击点和回收状态。
5. 设置一键测试：撞地面、撞围栏、圈内空洞通过测试障碍物、改变倾角。
6. 每次投掷完成后清理旧物理对象，不出现无限刚体/内存累积。

**本阶段明确不做**：鹅颈套中判定、正式成绩、AI、广告/商城、最终美术。

**验收**：PH-01 / PH-02 / PH-03；给出至少三个可重现测试场景，说明物理圈不是一个实心盘。完成后报告实际命令和结果，停止等待确认。
