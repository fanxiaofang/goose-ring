# Prompt：P2 静态场新手引导、基础存档与经济模拟（P1 人工验收后使用）

> 当前状态：待执行。只有 P1 三模式核心可玩闭环经负责人签收后才能开始。

## 目标

三模式玩法已经成立后，再补新手理解、跨次游玩和基础资源循环。不得回头重做已验收的套圈物理和活动鹅核心玩法。

## 范围

### 1. 静态场新手引导
- 首次进入静态场时分步引导：起手区 → 方向 → 力度 → 松手。
- 展示轨迹/预测落点辅助，允许从设置关闭或调整。
- 引导按正式场规则消耗圈，不提供无限免费投掷；单鹅调试直达仍只供内部使用。

### 2. 基础本地存档
- 记录个人累计、静态/普通/机灵分模式累计、正式投圈数、准确率、清摊数和各模式 Board。
- 每次 CAUGHT 幂等写入：同一 throwId、同一 Board 内同一 gooseId 不重复累计。
- 刷新/重新进入后，当前盘和历史累计保持一致；破损或旧版本存档有明确回退提示。
- 本阶段仅做本地存储，不伪装成跨设备云同步或真实在线排行。

### 3. 币/圈经济模拟
- 每日领取、币兑换圈使用配置化数值；20 币→20 圈、50 币→60 圈仍是候选值，可通过试玩调整。
- 领取/兑换操作幂等，避免重复送币或重复扣币。
- 广告入口只做清晰占位或隐藏，不虚构广告展示成功。

## 不做

真实广告 SDK、分享奖励、支付、云存档、在线排行榜后端、跨平台账号、抖音 SDK。

## 最小验收

- 静态场首次进入能理解如何投圈。
- 三模式各自累计不串场；套中即时写入，刷新后不丢、不重复。
- 币圈兑换和领取可重复点击而不重复记账。
- 单鹅调试直达不会改变任何正式资源或统计。
- 完成 typecheck、build 和存档/事务相关定向测试；不做无关的物理压力测试。
