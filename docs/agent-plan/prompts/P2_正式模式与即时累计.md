# Prompt：P2 正式游戏核心闭环（P1 人工通过后使用）

请实现 GDD v1.1 的正式核心循环。不要设计新关卡或替换用户确认的计数逻辑。

**本次范围**：
- 普通鹅和机灵鹅两个正式入口，正式圈共用库存；每模式有自己的 8 只鹅盘（数量可配置），允许继续/换盘/跨天恢复。
- 鹅群基本漫游、边界/分离、个体察觉率/延迟/冷却与低头歪头躲避；不得瞬移完美闪避。
- 每个正式投圈使用 throwId，投掷结束只结算一次。
- 一个鹅被有效套住之后，**立即在同一可靠存储提交中**更新 Board caught 集合、模式累计、历史总数以及投掷数据；确认保存后才展示永久 +1。不要等“这盘结束”才记鹅。
- 清摊只是本盘全 8 鹅完成时的庆祝/成就，不额外重复计数；漂亮清摊门槛使用配置初值。
- 练习与正式完全隔离；正式无“每局 20 个圈”；可随时离开，不强制耗光库存。
- 个人纪录：累计鹅、普通/机灵分项、投圈次数、准确率、清摊/漂亮清摊次数。
- 币/圈本地**模拟**接口与界面可在本阶段增加，候选值是每日 20 币、20 币换 20 圈、50 币换 60 圈，但必须配置化；不要调用真实广告 SDK、虚构分享已奖励。
- HUD 不盖鹅栏、设置可暂停而不误投圈。

**测试必须包含**：DA-01～DA-13。尤其测试 CAUGHT 立刻关网页再打开、重复结算回调、清摊后历史不重复 +8、跨天继续、币与圈事务一致性、中断投掷的明示处理策略。

**不要做**：云端排行榜、广告 SDK、分享领币、省份榜、摊主完整指挥与骨骼模型、复杂美术。

报告真实测试证据和待决策项，完成后停止等待我确认是否进入 P3。
