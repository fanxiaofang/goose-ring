# Prompt：P0-0 技术底座（第一轮，只运行这一条）

> v0.2 接手说明：以下为原始初始化提示词。现有仓库已实现此阶段，当前手机与相机基准见 [P0-L 规范](../05_主游戏场景构图与布局执行规范.md)。

请以 `GDD_v1.1_设计基线.md`、`01_技术方案.md`、`02_阶段任务.md`、`03_验收测试.md` 为依据，实现 **P0-0**：

**目标**：创建或完善一个可在横屏手机浏览器运行的 Three.js + Rapier 3D 物理灰盒场景，不做完整游戏。

**严格范围**：

初始化工程时必须遵循 `01_技术方案.md` 的目录架构，不要为了 P0-0 额外创建不需要的模块或平台工程。

- Vite + TypeScript + Three.js + `@dimforge/rapier3d-compat`；确认实际依赖及构建。
- 固定 OrthographicCamera，初始相对水平面俯视 38°，提供 30/38/45° 调试切换。
- 统一 Y-up / XZ 地面 / Z+ 靠近玩家，建立大围栏、清洁地面、简易灯光；3D 几何体即可。
- Rapier WASM 初始化、固定步物理更新、调试可视化；投下一颗测试球到地面证明碰撞有效。
- 横屏 16:9 设计基线和宽屏响应，非横屏时提示旋转。
- 用鼠标与触摸测试基础输入；编译、运行、确认控制台没有持续报错。

**不做**：套圈、鹅模型、套中判定、积分、广告、练习、排行榜、收藏、完整音频与美术。

**完成证据**：列出修改的文件；粘贴实际执行的安装/构建/测试命令和结果；能查看相机切换、地面碰撞、围栏、横屏提示；给出启动命令以及本机/手机怎么打开。停止在 P0-0，等待我验收。
