# Prompt：P0-4 普通场与机灵场活动鹅核心玩法

> 进入条件：P0-3 动态头颈与 RingJudge 同步已签收；WX-0 微信最小运行验证已完成或因账号/权限原因明确记录阻塞。当前目标是先做出可玩的活动鹅，不做完整产品系统。

## 1. 目标

让普通场和机灵场的鹅真正走动、察觉套圈并做出可读的躲避动作。两种模式共用同一套轻量 AI，仅由参数配置产生难度差异。静态场保持现有行为，不受影响。

## 2. 必须先读

- 根目录 AGENTS.md
- GDD §4、§7、§14；01 技术方案；02 阶段任务；03 验收测试；04 决策与参数
- P0-2 和 P0-3 的已验收报告
- 当前鹅、物理、RingJudge、Board 和模式配置源代码

## 3. 最小实现范围

### A. 基础漫游

- 普通场/机灵场各使用现有 8 鹅布局作为初始散布。
- 每只鹅选择局部移动目标，走走停停，方向和停留时间有个体差异。
- 接近围栏时转向；接近其他鹅时做简单分离/避让，避免明显重叠。
- 不实现完整 Boids、复杂群体心理或大规模寻路。

### B. 套圈察觉与躲避

- 使用真实投圈轨迹预测圈是否进入鹅的威胁区域。
- 按 GDD 的顺序执行：察觉概率 → 随机反应延迟 → 选择可见动作（低头、左躲、右躲）→ 动作持续时间 → 冷却。
- 不允许最后一刻瞬移；玩家必须能看见动作前兆，并有机会通过观察抓时机。
- 同一只鹅不能对同一圈重复触发躲避；圈飞离威胁区后不继续追踪。
- 鹅的头颈动作继续通过 P0-3 的同一 PoseSnapshot 驱动视觉、Collider 和 RingJudge。

### C. 两种模式参数化

- 普通场：察觉较低、反应延迟较长、躲避幅度/速度较温和。
- 机灵场：察觉较高、反应更快、躲避能力更强，但仍有失败察觉和可命中的窗口。
- 数值从 GDD 原型参数起步，集中配置，不散落 magic numbers；通过试玩调整，不把参数解释成真实动物品种特征。
- 不为两个模式复制两套 AI 代码。

## 4. 不做

摊主指挥、赶鹅按钮、完整 Boids、复杂性格树、多品种美术、正式 GLB、广告、排行榜、币圈经济、云存档、好友 PK 和抖音适配。

## 5. 最小验收

- 普通场：鹅会移动、走停自然、会出现察觉/未察觉/反应慢/躲避等结果。
- 机灵场：同一套规则下行为明显更敏锐，但不是每次都完美躲开。
- 玩家能从画面看懂鹅为何躲避；没有瞬移式作弊动作。
- 鹅与围栏、鹅与鹅没有明显持续穿模；若出现具体问题，按复现位置修复，不做泛化大压力测试。
- 至少保存普通场、机灵场各一条固定 seed 行为重放。
- 负责人分别试玩普通场和机灵场 5 分钟左右，判断差异是否清楚、是否愿意继续投圈。
- 只添加漫游、威胁判断、状态切换和边界行为所需的定向测试；阶段结束跑 typecheck、build 和受影响测试，不做 100 次投圈压力测试。

## 6. 交付

- 两模式行为参数表及修改理由。
- 普通场和机灵场各一段录屏/固定 seed 重放。
- 一条察觉后躲避、一条未察觉或反应慢的案例。
- 实际测试命令和结果；未测试项明确标注。
- 已知问题、风险和回退方法。
