# Prompt · P0-L 手机横屏场景布局

使用前请确认项目负责人已评审 [主游戏场景构图与布局执行规范](../05_主游戏场景构图与布局执行规范.md)。先读根目录 `AGENTS.md` 和 [v0.2 启动提示词](../START_HERE_PROMPT.md)，核对代码及现有改动，列影响文件、方案与验收条件，再开始实现。P0-0/P0-1 直接在现有原型上回归。

1. 以 844×390、667×375 CSS px 和非对称安全区为主，按规范实现相机取景与投影对齐。场地 16×10 m、当前 8 鹅坐标、投掷线与出手点沿用代码。
2. 做顶部横向入口/HUD 的灰盒、大厅与投掷态的调试切换、仅大厅显示的右侧竖向广告位线框、底部独立起手区及说明。广告位按评审通过的尺寸落地。实现指针进入/移出/取消的区域边界，保留现在的蓄力、角度、速度与 Rapier 逻辑。
3. 保留碰撞、相机调试能力。显示可用区、围栏和关键世界元素的投影尺寸、UI 矩形及热区边界。以透视（垂直 FOV30°、俯视30°、偏航0°）为默认。先核对大厅、正式场、练习场的内容，再按用户批准的取景检查远鹅尺寸和纵深。
4. 执行 [PL-01～PL-07](../03_验收测试.md#2-p0-l-手机横屏布局矩阵)，提供两个尺寸的 A/B 截图、非对称安全区与触摸证据。执行 `npm run typecheck`、`npm run test`、`npm run build`。报告测试环境、结果、截图位置和未验证项。

本阶段是布局灰盒和既有输入的区域验收。模式业务、商业化、摊主和实际投掷参数优化各按对应关口安排。交付后暂停，由项目负责人确认手机布局。
