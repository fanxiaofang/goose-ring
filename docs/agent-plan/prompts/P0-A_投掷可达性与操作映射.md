# Prompt · P0-A 投掷可达性与操作映射

P0-L 已暂时验收通过。本提示词经项目负责人确认后执行。先读 [接手提示词](../START_HERE_PROMPT.md) 所列基线，核对工作树并列影响文件、方案和验收条件。

1. **复跑现行基线。** 从 `gameConfig` 读取运行值，保留 P0-L 的 FOV30°、Play Rect、抓圈区和 32 CSS px 底部兜底带。围栏近侧 `z=5.00`，线 `z=5.43`（D-20261126-007 后移），默认出手 `(0, 1.85, 6.10)`，仰角 `30°`，最高 `11.8 m/s`，横移 `±1.15 m`、偏转 `±40°`。先跑 `ringPhysics.test.ts` 的静态场三档站位八鹅样本，并保留原站位的四个回归用例。旧的左后鹅失败记录供历史对照。分别记录调整输入前后的结果。
2. **接入三种手势。** 复用现有 Pointer Events、合法起手、指针捕获、起手时的尺寸和统一出手路径。竖向意图未过阈值时按住计时并允许横拖瞄准。首次明确下拉锁定拉距蓄力，左右分量仍用于瞄准。首次明确上甩锁定甩投，建议在松手时按位移门槛及释放前短窗口的速度确认出手。慢推或短扫未过门槛则取消。下拉后回推只减弱或取消原手势。阈值和力度曲线集中配置，用两种视口与实测输入调校。分别验证抓圈和底带，记录底带向下的实际可用行程。
3. **统一发射与回归。** 从同一份解析后的发射描述驱动预览、实投和重放，核对初始位置、速度、姿态、重力和当前调试线阻尼。预测只表示无遮挡轨迹，记录首碰前偏差和实际地面首碰位置。轻点、第二指、取消、失捕获、转屏、视口实际变化及暂停或设置中断均须覆盖。一次成功出手只扣一圈，末圈、暂停恢复和练习免扣圈按 PL-07 回归。长按切出用实际事件记录区分宿主动作与页面变化，未复现时注明。
4. **逐鹅取证。** 复用 `PhysicsWorld`、当前八鹅配置和固定步进，保留所有正常场景 Collider。为每只鹅给出可由合法手势产生的名义输入、能通过的邻近组合和失败对照。保存输入或可重放参数、发射状态、首碰对象和步号，以及下降时鹅头穿过真实环孔、随后颈区进入环孔的证据。地面射程、垂直落颈预设和手工指定初速用于诊断。若余量不足，先定位输入行程、射程或碰撞原因，再单变量对照。改围栏、鹅体尺寸或整体站位前提交实测与取舍。
5. **交付验收。** 执行 [PA-01～PA-05](../03_验收测试.md#3-p0-a-投掷可达性矩阵)、P0-1 物理和 PL-01～PL-07 回归，给出八鹅结果表、近中远手势复现、两种视口证据、实际命令结果和待补真机项。自动重放用于验证物理路径，手机触摸用于验手感。交项目负责人确认后再进 P0-2，正式 `CAUGHT`、稳定期与计分由 P0-2 及后续阶段负责。
