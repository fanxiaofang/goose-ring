# Prompt · P0-A 投掷可达性与操作映射

P0-L 人工通过后使用。先阅读 [布局规范](../05_主游戏场景构图与布局执行规范.md)，以及 [D-20261124-017](../04_决策与参数.md#d-20261124-017-前栏立柱木栈道与投掷校准)（现行出手参数）与 [D-20261123-009](../04_决策与参数.md#p0-1-决策记录)（可达性模型），锁定批准的手机构图，列影响文件和验收条件。

1. 按当前代码记录近栏 `z=5.00`、线 `z=5.55`、出手 `(0, 1.85, 6.10)`、仰角 `30°`、最高 `11.8 m/s`、手持横移 `±1.15 m`、偏转 `±40°`、按住计时蓄力和横拖映射。先复现现有后排问题，用同一批输入比较候选修正。
2. 从真实用户可生成的初始状态做逐鹅 Rapier 重放。保留其它鹅、围栏、地面和圈 Collider。记录名义输入、邻近可通过输入、失败原因、首碰与穿越。须覆盖左后 G1 和两只后排低裕量样本，以及近中远的正反例。地面落点另报告，`CAUGHT` 的正式稳定期和状态机进入 P0-2 再实现。
3. 用同一份发射状态驱动视觉预览与实投，核对两种手机视口映射、预测的可见性和首碰前偏差。预览表示无遮挡地面落点，保留真实碰撞和越界反馈。
4. 若覆盖失败，先对目标局部位置、初速或仰角逐项试验，记录对近鹅、远栏、手势容差和构图的影响。若涉及围栏/鹅实体尺寸或场地级调整，提交取舍供评审，同步检验视觉和碰撞几何。
5. 执行 [PA-01～PA-05](../03_验收测试.md#3-p0-a-投掷可达性矩阵) 和 P0-1 回归。每只鹅给实测证据，标出手机真机与自动重放的范围，交由人工验收后进入 P0-2。
