# Prompt：P1 静态/普通/机灵三模式核心可玩闭环（P0-4 人工验收后使用）

> 当前状态：待执行。只有 P0-4 经项目负责人人工签收后才能开始。本文件不是当前开发任务。

请按 GDD v1.1、01 技术方案、02 阶段任务和 04 决策记录，把三个玩家模式组成一个可连续试玩的核心游戏闭环。

## 目标

玩家能从大厅选择静态场、普通场或机灵场，进入独立鹅盘，真实投圈，套中后看到鹅友好退场并即时更新当前盘计数；全部套完可以清摊并开始新盘。

## 范围

- 静态场沿用已经验收的固定鹅玩法；普通场和机灵场使用 P0-4 已验收的活动鹅 AI。
- 三种模式分别初始化独立 Board；切换模式不得串用鹅的行为参数、盘面和当前计数。
- 每盘暂定 8 只鹅；套中一只立即从当前盘移除并计数 +1。
- 支持清摊、再开一盘、返回大厅和基本结算信息。
- 复用现有投掷输入、RingJudge、相机、布局和 HUD，不重做 P0-L/P0-A/P0-2。
- 当前阶段可使用开发态圈数或现有资源流程验证核心玩法；不要因真实广告、币制、云存档或在线榜单阻塞。

## 不做

新手分步教学、完整历史存档、真实币圈经济、广告、分享奖励、在线排行榜、支付、好友 PK、正式美术和抖音适配。

## 最小验收

- 三个模式都能从入口进入并完成投掷、套中、退场和重新开盘。
- 静态场鹅不移动；普通场/机灵场行为差异明显且符合 P0-4 验收。
- 三种模式各自的 Board 和当前盘计数隔离。
- 一次投掷最多套中一只；已退场鹅不再作为目标；重复事件不重复加当前盘计数。
- 每个模式至少人工完成一轮短试玩；记录阻塞体验的问题，不要求大规模压力测试。

交付改动文件、三模式试玩入口、每种模式一段短录屏/截图、必要测试结果和未解决问题。完成后停下等待负责人验收。
