# 03 验收与测试｜让“看起来能玩”变成“确实可信”

> 目的：给本人和 Agent 一套**可以操作、可以复现、可以判断过/不过**的标准。P0–P2 执行期间逐渐实现；不要求 P0 就通过全部业务测试。

## 1. 标准测试环境

- 电脑浏览器：能用鼠标复现拖动投圈，检查控制台、WebGL/WASM 加载与 FPS。
- 横屏手机：至少一部真实手机，测试触摸热区、拖动、音频、屏幕安全区、切后台恢复。模拟器**不能替代**真机手感。
- 可调相机：30°、38°、45°；16:9 与更宽横屏可视区域。
- 开发态开关：碰撞线框、路径线、鹅头颈轴线、RingJudge 状态、飞行速度、Throw ID / Goose ID、固定物理 tick、随机 seed、物理慢动作。
- 固定种子：至少 3 套可重复场景；禁止用“随机结果刚好通过”掩盖不稳定。

## 2. P0 物理和命中矩阵

| 编号 | 操作/场景 | 期望 | 失败时要记录什么 |
|---|---|---|---|
| PH-01 | 圈按预设速度飞行，落到无遮挡地面 | 路径合理，有弹跳和摩擦，无明显地面穿透 | 速度、姿态、step、CCD |
| PH-02 | 圈正面撞栏杆 / 擦栏杆顶部 | 被实体阻挡或合理反弹，无幽灵穿栏 | 栏 Collider 截面、接触日志 |
| PH-03 | 调整环内孔，向空洞穿过小物体 | 内孔真实存在，不能被实心盘阻挡 | 圈段位置、相邻碰撞体间隙 |
| PH-04 | 正上方将环套过头部，落到颈部并稳定 | RingJudge `CAUGHT` 一次 | 穿越记录、脖颈位姿、稳定时长 |
| PH-05 | 环碰到鹅头顶部 | `MISSED`，头部受力/反弹可见 | 头 Collider/碰撞事件 |
| PH-06 | 环碰到鹅身或翅膀 | `MISSED` | 拍摄截帧与判定日志 |
| PH-07 | 环从颈部侧面贴近 | 无非法穿入、不得计为套中 | 圈中心轨迹、环平面朝向 |
| PH-08 | 进入颈部但稳定期内滑脱 | `MISSED`、不提前 +1 | 时间轴、判定状态转换 |
| PH-09 | 环可能同时接触两个鹅 | 最多一只计数，赢家判定可解释 | throwId / gooseIds / contact order |
| PH-10 | 鹅低头、歪头、抬头中投圈 | 视觉与头颈 Collider 同步 | 每一物理步骨骼/碰撞体差值 |
| PH-11 | 两只鹅挤在一起、靠围栏 | 身体主碰撞体不交叉，不穿栏 | 最小分离距离、修正次数 |
| PH-12 | 连续投 100 圈 / 降低帧率 / 切后台 | 没有持续穿模、状态不双结算、恢复后正常 | FPS、物理耗时、泄露数、异常计数 |

**补充：**“100 次全部没有穿模”不等于数学上永不穿透；必须记录最差交叉深度、复现场景和可视异常，确保正式镜头下不可见、判定可靠。

## 3. P1 操作与练习矩阵

| 编号 | 输入 | 预期 |
|---|---|---|
| OP-01 | 左右拖动，同力度 | 水平目标方向单调、可预测变化 |
| OP-02 | 同方向不同拉动距离 | 初速度/飞行距离随力度合理变化，触发夹紧防过大 |
| OP-03 | 实投 vs full 轨迹 | 假设无遮挡的轨迹与预测一致，预览不等于命中保证 |
| OP-04 | 实投 vs landing 环 | 地面预计首次落点合理，不吸附到鹅身上 |
| OP-05 | 打开设置 / 点击 HUD / 多点触摸 / 触摸取消 | 不误发射，暂停后恢复正确 |
| OP-06 | 第一进入领取 30 练习圈并用完 | 余额恰好 0，正式库存和累计不变 |
| OP-07 | 刷新/重开/切到另一个页面 | 剩余练习圈不重复发、不丢失 |
| OP-08 | 手机横屏安全区和静音 | 操作区无遮挡，鹅脖可见，音量开关生效 |

## 4. P2 统计与一致性矩阵

| 编号 | 步骤 | 预期 |
|---|---|---|
| DA-01 | 普通场一只鹅正式 CAUGHT | 当前盘 +1、普通累计 +1、总数 +1，并已保存 |
| DA-02 | 成功后立即刷新网页 | 盘面成功状态和总数一致，无重复入账 |
| DA-03 | 同个 throwId 重复触发 CAUGHT / 回调 | 入账至多一次 |
| DA-04 | 同只鹅在同盘二次成功 | 不重复计数 |
| DA-05 | 切普通/机灵，退出再回来 | 两盘独立，累计分别维护，共用正式圈库存 |
| DA-06 | 8 只鹅全套，触发清摊 | `clearCount` +1，历史鹅总数不二次加 8 |
| DA-07 | 换盘、改模式、清摊后重新玩 | 旧历史累计保持，新盘 ID 不冲突 |
| DA-08 | 练习场套中 5 只 | 正式所有数字不变 |
| DA-09 | 中断投掷（关闭网页 / 暂停） | 按**明确策略**处理未完成投掷，且不会多扣/多送圈；产生日志 |
| DA-10 | 连续点领取、兑换或手工重放事务 | 幂等，无重复送币送圈；P2 模拟版可检验 |
| DA-11 | 首次进入、版本升级或破损存档 | 清晰恢复/迁移/错误提示，不悄悄清空成功记录 |
| DA-12 | 一次成功发生存储失败 | 不提前展示“永久到账”；可以提示重试与恢复 |
| DA-13 | 使用不同设备/浏览器 H5 | 不虚构跨设备同步；没有后端时告知本地保存范围 |

## 5. 体验与动物友好验证

找 5–10 位使用真实手机的试玩者，记录而非预设结果：

1. 是否无需长说明就懂得怎样拉动/松手？
2. 玩家套不中时，能否准确解释偏短、偏远、撞头还是鹅躲开？
3. 辅助轨迹是否有帮助？30 个练习圈是否太少？
4. 普通场与机灵场差别是否明显、可学习？
5. 套中后鹅的反应是否轻松、友善，是否有人觉得在伤害动物？
6. 俯视 30/38/45° 哪个最易看清脖子与圈？
7. 是否愿意再投圈、再试清摊？哪些动作令人发笑或不舒服？
8. 鹅叫、摊主和环境声关闭后是否能舒适玩？
