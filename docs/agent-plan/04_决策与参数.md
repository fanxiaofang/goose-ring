#### P0-1 决策记录

**D-20261123-001 真实有孔套圈的碰撞方案**
- 需求来源：02_阶段任务.md P0-1、AGENTS.md §5；P0-0 评审要求“不能用球体代替、不能只有视觉内孔”。
- 备选：实心圆盘 Collider（否决，中心无法穿过）；Torus 网格凸包（Rapier 无原生 torus，凸包会填满内孔）；16 段胶囊环（采用）。
- 最终选择：16 段胶囊围成闭合环，段间圆帽重叠，内孔净半径 0.375 m。
- 状态：已确认（几何与物理单测均通过）。
- 受影响文件：`src/ring/ringGeometry.ts`、`src/ring/ringBody.ts`、`src/physics/PhysicsWorld.ts`、`src/ring/RingSystem.ts`。
- 回退方案：若真机稳定性不足，可增减段数或改多面体环，但不得改为实心盘。

**D-20261123-002 相机取景测试改为屏幕构图验收**
- 需求来源：P0-1 评审遗留问题 5。
- 证据：旧断言只比较“注视点平面可视高”，无法反映围栏顶部 UI 带、前栏位置与鹅头安全区；且 P0-0 后期主动收紧透视取景，使 1.1 m 容差失去意义。
- 最终选择：直接投影围栏四角与实验鹅头到屏幕百分比，验收顶部/底部 UI 安全带与围栏占屏；A、B 纳入正式候选断言，C 保留实验。
- 状态：已确认。
- 受影响文件：`src/cameraUtils.test.ts`。

**D-20261123-003 P0-1 单鹅测试场景与固定投掷**
- 需求来源：P0-1 评审“优先使用单只静止鹅进行套圈实验”“保留确定性测试条件”。
- 最终选择：`?geese=single` 用离玩家最近的鹅，视觉与 Collider 同步缩减；固定投掷全部写死参数、无随机项；`?throw=` 与“重放上次”使用完全相同的初始条件。
- 状态：已确认。
- 受影响文件：`src/app/GameApp.ts`、`src/ring/throwPresets.ts`、`src/physics/PhysicsWorld.ts`、`src/scene/GameScene.ts`。

**D-20261123-004 透视相机改为窄视场 + 宽高比自适应后拉**
- 需求来源：用户相机修正要求（`PerspectiveCamera(25, aspect, 0.1, 80)`、保留纵深、避免广角畸变、锁定相机、窄屏整体入画）。
- 备选：固定距离（窄屏会裁掉左右栏角，否决）；缩小 FOV 或移动注视点（改变构图语义，否决）；仅按宽高比后拉（采用）。
- 最终选择：保留 A/B/C 三模式与 30° 俯视、0° 偏转；透视模式按围栏外沿角点解析求最小距离，正交模式不变。
- 状态：已确认（typecheck/build 通过，26 项单测通过，16:9 与 4:3 实机截图核对）；A/B 正式取舍仍待真机手感对比。

### D-20261126-008 P0-2 套中判定 RingJudge（稳定期 0.25s 起步、穿越证据驱动、一投一只）

- 需求来源：用户确认按评审方案实现 P0-2：稳定期 **0.25 s 起步**（实测可上调），一条投掷最多套中一只，多鹅按**最早入颈者优先**；沿用三条既有口径——头必须先过孔、必须从上方下落入颈、圈停在颈根。
- 判定口径：
  1. **穿越证据驱动**：`FLYING → ENTER_NECK → SETTLING → CAUGHT | MISSED`。环必须沿自身法线向下运动（`linvel·法线 < -0.1`），先有鹅头从环平面下方穿到上方的证据；随后颈中心由下往上穿过环平面，且**竖直颈轴落在内孔内**（`< 0.375 m`）才锁定入颈。最初要求“整个头/整根颈截面都在孔内”（0.159 / 0.2454 m），实测真实斜抛几乎达不到，会导致环已挂在脖子上却判 MISS；按 GDD §6.3「宁可容差，不要看起来中了却没中」放宽为孔内即可。
  2. **多鹅**：同一物理步多只同时入颈取穿越点距环轴最近者；不同 tick 则最早入颈者先锁定，锁定后其余鹅一律忽略。每个 judge 实例只结算一次（幂等）。
  3. **稳定期**：锁定后，只要「竖直颈轴与环平面的交点」到环轴的距离 `< 内孔半径 0.375 m`，累计满 0.25 s 即 CAUGHT；颈轴离开内孔判 `slip`。稳定期不再单独按倾斜判负（已挂在颈上的环歪一点仍是套中）。另有静止兜底：未锁定但环基本静止、低于颈中心且竖直颈轴落在孔内时，判 CAUGHT（避免“已挂在脖子里却因穿越瞬间倾斜偏大漏判”）。
  4. **头/身接触不立即判负**：内孔仅比鹅头略大，斜抛下落时环管会贴着鹅头侧面滑过再套到颈上（实测名义投掷持续头/颈接触 20+ tick）。接触只作失败归因：未入颈就落地或静止时，回报最近 0.5 s 内的头接触（`head-hit`）/身接触（`body-hit`），否则 `ground`。这修正了「一碰头就 MISS」会把 8 只鹅的合法名义投掷全部误杀的问题。
  5. **倾斜容忍**：`maxTiltDeg` 由初定 55° 上调为 **75°**。实测鹅头穿越瞬间环最多倾斜约 69°、颈穿越约 61°；55° 会误杀 7/8 只名义鹅，75° 仍能排除接近竖直的侧向穿颈。
  6. **退场占位**：CAUGHT 后鹅与本圈即时隐藏/移除，退场动画留待美术阶段；本轮不做计分、正式累计与鹅群 AI。
  7. **退场鹅不再作为目标**：`RingJudge` 支持 `excludeIndices`，每投新建时由 `GameApp` 传入已套中的鹅序号。已退场鹅保留占位（保证 `gooseIndex` 与原始布局对齐）但不参与锁定，避免把环扔到原位置时“幽灵锁定”已退场的鹅。
